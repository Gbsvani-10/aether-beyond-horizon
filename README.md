# 🌌 AETHER — Beyond the Horizon

### An Immersive Interactive Parallax Experience

**AETHER** is a cinematic web experience that takes visitors on an interactive journey through mysterious fantasy worlds. Explore floating islands, enchanted forests, celestial portals and breathtaking landscapes through smooth, multi-layer parallax scrolling and immersive visual interactions.

> Every journey begins beyond the horizon.

---

## ✨ Features

- **Multi-Layer Parallax Scrolling:** Experience different movement speeds across foreground, middle-ground and background elements.
- **Cinematic Environments:** Explore five visually rich fantasy-inspired worlds.
- **Floating Islands:** Discover magical landscapes with interactive 3D elements.
- **Dynamic Day-to-Night Transitions:** Watch environments transform as you progress.
- **Interactive Portals:** Travel between different environments through animated transitions.
- **Particle Effects:** Enjoy floating stars, fireflies, magical dust and atmospheric effects.
- **Crystal Quest:** Discover hidden collectibles throughout the journey.
- **Secret Environment:** Unlock a hidden world by completing the exploration challenge.
- **Cinematic Auto-Explore:** Experience the journey with automated camera movement.
- **Responsive Design:** Optimized for desktop, tablet and mobile devices.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm or Bun
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Gbsvani-10/aether-beyond-horizon.git
```

Navigate into the project:

```bash
cd aether-beyond-horizon
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

---

## 🎨 Design Philosophy

The experience focuses on three important principles:

1. **Depth:** Create a sense of distance through multiple independently animated visual layers.
2. **Exploration:** Encourage visitors to discover hidden interactions and environments.
3. **Immersion:** Combine smooth animations, atmospheric effects and cinematic transitions into one connected journey.
